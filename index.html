Videojuego.java 
// 1. CLASE Jugador: plantilla que define al héroe
class Jugador {
    // ATRIBUTOS: estado y características del objeto
    String nombre = "Aria";
    int vida = 100;
    double ataque = 25.5;

    // MÉTODO: comportamiento o acción del jugador
    public void atacar(Boss enemigo) {
        double danioReal = ataque * 1.2; // VARIABLE local
        enemigo.vida -= danioReal;       // INSTRUCCIÓN acabada en ;
        System.out.println(nombre + " inflige " + danioReal + " de daño.");
    }
}

// 2. CLASE Boss: plantilla para el enemigo jefe
class Boss {
    String nombre = "Dragón Ígneo";
    double vida = 300.0;
}

// 3. CLASE Principal: punto de entrada del programa
public class Principal {
    // MÉTODO main(): punto de inicio ejecutado por la JVM
    public static void main(String[] args) {
        Jugador p1 = new Jugador(); // Instrucción de instanciación
        Boss jefe = new Boss();
        p1.atacar(jefe);
    }
}

05. Uso de Paquetes (import)

Java agrupa sus clases estándar en paquetes jerárquicos para evitar conflictos de nombres y organizar librerías.

Importación puntual (Recomendada) import java.util.Scanner;

Importa exclusivamente la clase Scanner del paquete java.util.

Importación global con comodín (*) import java.io.*;

Importa todas las clases directas del paquete java.io (no incluye subpaquetes).

Paquete por defecto: java.lang

Clases como String, System o Math están disponibles sin necesidad de import.

06. Lectura por Teclado con Scanner en 4 Pasos

Paso 1 · Importar

import java.util.Scanner;

En la cabecera del archivo .java.

Paso 2 · Instanciar

Scanner entrada = new Scanner(System.in);

Asocia el objeto al flujo estándar de entrada.

Paso 3 · Mostrar mensaje

System.out.print("Dato: ");

Indica al usuario qué tipo de valor se espera.

Paso 4 · Capturar dato

entrada.nextInt() / nextLine()

No cierres System.in si vas a seguir leyendo en otros métodos.

import java.util.Scanner; // Paso 1: Importar Scanner

public class LecturaDatos {
    /**
     * Solicita el nombre al usuario y lo devuelve como String.
     */
    public static String pedirNombre() {
        Scanner entrada = new Scanner(System.in); // Paso 2: Instanciar
        System.out.print("Introduce tu nombre: ");  // Paso 3: Indicar al usuario
        return entrada.nextLine();                // Paso 4: Capturar dato
    }

    public static void main(String[] args) {
        String nombre = pedirNombre();
        System.out.println("¡Hola, " + nombre + "!");
    }
}

01. Flujo Secuencial vs. Estructuras de Control de Flujo

⬇️

Flujo Secuencial

Ejecuta las sentencias una tras otra en orden lineal, de arriba hacia abajo, sin bifurcaciones.

🔀

Condicionales

Eligen qué bloque ejecutar según expresiones booleanas (if, if-else, switch-case).

🔁

Bucles (Iteración)

Repiten instrucciones mientras se cumpla una condición (for, while, do-while).

🚫

Evitar Saltos Bruscos

Evita break en bucles o return; vacíos: rompen la programación estructurada y dificultan la depuración. Usa banderas booleanas.

🛡️

Control de Excepciones

Bloques try-catch que interceptan fallos en ejecución (ej. InputMismatchException) sin detener la aplicación.

03. Patrón Obligatorio: Menú Robusto Modular (do-while → try-catch → switch-case)

Diseñado con métodos cohesivos mostrarMenu() y pedirOpcion(), sin cerrar Scanner y sin sentencias de salto en bucles.

1. Capa Exterior: do { ... } while (opcion != 4); Repetición
2. Capa Media: try { ... } catch (InputMismatchException e) Blindaje + entrada.nextLine()
3. Capa Interior: switch (opcion) { case 1..4 / default } Selección

🧪 Simula una entrada en pedirOpcion():

// Pulsa "Simular entrada" para trazar la ejecución modular
MenuRobustoModular.java 
import java.util.InputMismatchException;
import java.util.Scanner;

public class MenuRobustoModular {
    /**
     * Muestra por consola las opciones disponibles del menú.
     */
    public static void mostrarMenu() {
        System.out.println("\n--- MENÚ PRINCIPAL ---");
        System.out.println("1. Saludar | 2. Calcular | 3. Info | 4. Salir");
    }

    /**
     * Lee y valida un número entero como opción de menú.
     * @return opción entera válida o 0 si hubo error de formato.
     */
    public static int pedirOpcion() {
        Scanner entrada = new Scanner(System.in);
        int opcion = 0;
        try {
            System.out.print("Elige una opción: ");
            opcion = entrada.nextInt();
        } catch (InputMismatchException e) {
            System.out.println("Error: Debes introducir un número entero.");
            entrada.nextLine();
        }
        return opcion;
    }

    public static void main(String[] args) {
        int opcion;
        do {
            mostrarMenu();
            opcion = pedirOpcion();
            switch (opcion) {
                case 1: System.out.println("¡Hola, programador/a!"); break;
                case 2: System.out.println("Resultado: 2 + 2 = 4"); break;
                case 3: System.out.println("Menú blindado RA1-RA3"); break;
                case 4: System.out.println("Saliendo del programa..."); break;
                default: System.out.println("Opción fuera de rango (1-4).");
            }
        } while (opcion != 4);
    }
}
